# 分析文档目录

本目录存放对 KOL 访谈/播客的深度分析文件。每个文件是对一个 KOL 访谈的深度解读，包含推理链、交叉引用和核心论点提取。

## 目录结构

- **分析文件**：150 篇 KOL 深度分析，涵盖 AI 领域关键人物的访谈解读
- **关联逐字稿**：对应的原始逐字稿在 `transcripts/` 目录
- **知识图谱**：`knowledge-graph/` 目录存放 AI 行业知识图谱文件
