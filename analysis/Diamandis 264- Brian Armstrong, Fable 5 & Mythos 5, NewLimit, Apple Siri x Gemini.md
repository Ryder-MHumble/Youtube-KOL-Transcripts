## NewLimit 的进展是闭环实验系统，不是已经实现寿命逃逸速度

Armstrong 创办 NewLimit 的核心判断是长寿研究当时相对缺少强团队和资本。他们选择表观遗传重编程，希望恢复细胞年龄而不改变细胞类型。

> **[1:24:43]** "And one of the folks mentioned epigenetic reprogramming, which is this area that talks about how you can reprogram cells. Um Shina Yamanaka famously won the Nobel Prize for this in 2012, showing you could reprogram an old skin cell into a young uh embryionic stem cell. And he by doing so with just these four proteins added to the cell he had this kind of remarkable discovery that he changed both the age of the cell and the type of the cell. So at new limit we're trying to do half of what Shiny Yamanaka did. We don't want to change the type of the cell we just want to change the age."

真正具有产品价值的是实验闭环：AI 从文献和内部湿实验数据提出组合，池化筛选寻找表型变化，再用功能实验判断细胞是否真的恢复能力，最后才进入动物和人体研究。

> **[1:25:44]** "And so it recommends the next set of experiments that we run in our wet lab. We do these poolled screens and see if phenotypically we can we can make cells look younger. Then we take the best hits out of that in the funnel and we put them through functional assays which are a little slower and more expensive to see if they actually act younger. Um, for instance, we might take a reprogrammed liver cell and see if it can process caffeine and acetaminophen and alcohol or whatever kind of like a young a young liver cell."

Armstrong 称公司已经在人类细胞上成功重编程，首批候选药计划次年进入临床。这是公司自报里程碑，不等于人体已证明安全有效。

> **[1:26:23]** "I thought this was going to be like a 5 or 10 year kind of basic research endeavor, but um we've actually been able to demonstrate successful reprogramming of human cells now in our first drug candidates going into the clinic next year, hopefully followed by a bunch more."

Alex 所谓 LEV 可能“spiky”是关于特定亚群和指标的假设。节目自己也承认表观遗传时钟波动，功能恢复比单一年龄数字更可靠。

> **[1:27:49]** "Uh perhaps unsurprisingly, I I will go out on a limb and say that I think LEV is going to be spiky in the same sense that AGI is spiky and that on certain spikes it seems possible it might be achieved later this year."

`4.35 亿美元`的主要用途也不是继续做软件式探索，而是承担多个临床试验的高成本、长周期和高失败率。

## 关键判断

1. **Agent 钱包不是 Agent 银行账户的完整等价物**：密钥和结算已经可用，身份、授权、撤销、审计与责任仍未解决。
2. **机器支付需要任务级预算**：每个 Agent 应拥有明确资金来源、用途、限额和上级责任主体，而不是无限自治钱包。
3. **链上信誉只能是风险信号**：交易图会受到女巫、循环交易和信誉购买攻击，不能替代法律身份与争议处理。
4. **政府持股同时制造财富分享和利益冲突**：监管者成为股东后，竞争中立、出售规则和政权更替风险必须制度化处理。
5. **高不确定性提高披露价值，而不是降低披露必要性**：IPO 应让市场看到模型折旧、资本开支和收入结构变化。
6. **SpaceX 的优势在物理执行与垂直整合**：轨道算力仍要通过每瓦推理、散热、发射、维修和折旧验证经济性。
7. **NewLimit 的核心资产是 AI-湿实验-功能验证闭环**：人类细胞重编程是前临床信号，LEV 仍是未经验证的时间线推测。
8. **安全版本分层需要可审计权限模型**：同一底模的不同 guardrail 版本不应只靠命名和价格区分。
9. **Apple 可以外包模型，不能外包用户入口**：个人上下文、权限治理和设备分发才是 Siri 的长期控制点。

## 深度关联
> 以下关联基于论点级分析：不是「都提到了X」，而是具体论点之间的逻辑关系

### Self-custodial wallet 提供机器账户，支付协议补上人类责任锚点
**→ [[Emily Sands- Token Heist 与 Agent 电商协议]]**
- 本文件论点：Armstrong 提出每个 Agent 通过 Base 获得无需传统 KYC 的 self-custodial wallet，并用链上交易图形成信誉（[23:51]、[24:13]、[29:47]）。
- 对方论点：Sands 的 shared payment token 将 Agent 支付绑定到人类用户凭证和授权范围，AEP 则定义商品、支付和结算交互。
- 关联逻辑：Armstrong 优先解决机器开户和全球结算，Sands 优先解决授权、可审计和商户接入。两条路径共同构成 Agent 金融栈：钱包提供持有与签名，协议提供交易语义，人类凭证提供责任锚点。只有钱包而无授权会形成责任真空，只有人类凭证而无机器钱包则无法支持 Agent 间原生经济。

### 从政府股权设想到客户级模型准入：利益冲突开始落到操作层
**→ [[Diamandis 267- Anthropic vs Alibaba, OpenAI IPO Delays, US Govt Blocks GPT-5.6]]**
- 本文件论点：圆桌讨论政府持有前沿实验室股权，Armstrong 担忧公共资本配置，Alex 指出监管者同时从既有企业成功中获利会压制新进入者（[40:39]、[47:47]）。
- 对方论点：#267 记录政府可能按客户身份分配前沿模型访问，准入控制从全面中断细化到客户级许可（[7:15]、[11:41]）。
- 关联逻辑：#264 提出监管者成为股东的结构性冲突，#267 展示监管者还可能掌握客户级分配权。两者合并后，政府不仅从某些实验室增值中获益，还能影响竞争者和客户能否获得能力。治理设计必须隔离投资、监管和采购职能，并公开准入标准与申诉机制。

### Agent 金融账户把任务经济学扩展到完整资金权限
**← [[Glenn Fogel- 不存在护城河与 agent 化旅行的 token 经济学]]**
- 本文件论点：Agent 可以拥有钱包和交易信誉，但仍需明确充值者、用途、限额、撤销和损失责任（[22:06]、[24:13]、[29:47]）。
- 对方论点：Fogel 要求旅行 Agent 按任务核算 token、模型路由、人工接管和 LTV，局部采用率不能替代完整单位经济。
- 关联逻辑：Fogel 解决任务消耗端，Armstrong 提供资金账户端。真正的 Agent 财务系统必须把二者连接：每个任务预算不仅包含 token，还包含支付、网络、人工和供应商费用；钱包不能只是余额容器，而要成为任务级损益、授权与审计的执行层。

### AI 缩短发现周期，但凡人计算提醒知识仍依赖具体载体
**→ [[Geoffrey Hinton 2022- 反叛自己]]**
- 本文件论点：NewLimit 用 AI 结合内部湿实验数据选择下一轮蛋白组合，再以功能实验和临床试验验证；数字搜索加速，生物载体和人体时间无法跳过（[1:25:44]、[1:26:23]、[1:34:43]）。
- 对方论点：Hinton 的凡人计算认为知识必须嵌入具体硬件并通过蒸馏传递，放弃可复制权重换取低能耗和物理适应性（[58:46]、[58:57]）。
- 关联逻辑：两者从碳基和硅基说明同一限制：信息模型不能替代承载它的物理系统。NewLimit 的 AI 可以搜索候选，却必须在细胞、动物和人体中重新获得证据；凡人计算的知识也不能脱离硬件直接复制。AI for science 的核心产品不是生成答案，而是缩短“模型假设→物理实验→新数据”闭环。
